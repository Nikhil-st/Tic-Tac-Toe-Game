Tic Tac Toe Game



A two-player Tic Tac Toe game built using HTML, CSS, and JavaScript.



Live Demo



https://nikhil-st.github.io/Tic-Tac-Toe-Game/



Features



\- Interactive 3x3 game board

\- Two-player gameplay

\- Winner detection

\- Draw detection

\- Reset and new game functionality



Technologies Used



\- HTML5

\- CSS3

\- JavaScript



Run Locally



1\. Clone the repository:

&#x20;  `git clone https://github.com/Nikhil-st/Tic-Tac-Toe-Game.git`

2\. Open the project folder.

3\. Open `index.html` in your browser.



Deployment



Hosted using GitHub Pages.



Configure it under \*\*Settings → Pages → Deploy from a branch\*\*, select `main` and `/(root)`, then click Save.
